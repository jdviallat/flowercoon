# Flowercoon — manifeste de mise à jour

Ce dépôt **public** contient uniquement `latest.json`, le manifeste de version
lu par l'application **Flowercoon** (par Bengacoon) à chaque ouverture pour
savoir si une version plus récente est disponible.

- `version` : dernière version publiée (ex. `2.0.0`)
- `notes` : nouveautés affichées à l'utilisateur
- `urlAndroid` : page Google Play (mise à jour côté Android)
- `urlIOS` : page App Store (mise à jour côté iPhone)
- `minVersion` : en dessous de cette version, la mise à jour devient obligatoire

Aucun code source ni secret ici — seulement les métadonnées de version.
